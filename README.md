### 🎨 **Modern Design System**

#### **Color Palette:**
```css
--primary-red: #8B0000      /* Main brand color */
--dark-red: #6C0320         /* Darker variant */
--primary-gold: #D4AF37     /* Accent color */
--light-gold: #FFD700       /* Lighter accent */
--text-dark: #2C3E50        /* Body text */
--text-light: #7F8C8D       /* Secondary text */
--white: #FFFFFF            /* Pure white */
```

#### **Typography:**
- **Headings:** Playfair Display (Serif, Elegant)
- **Body:** Poppins (Sans-serif, Modern)
- **Weights:** 300, 400, 500, 600, 700, 800

#### **Spacing System:**
- Sections: 5rem (80px) padding
- Cards: 2.5rem (40px) gap
- Elements: 1.5rem (24px) spacing

#### **Shadow System:**
- **sm:** 0 2px 8px rgba(0,0,0,0.08)
- **md:** 0 4px 16px rgba(0,0,0,0.12)
- **lg:** 0 8px 32px rgba(0,0,0,0.16)

#### **Border Radius:**
- Cards: 20px
- Buttons: 50px (pill shape)
- Images: 20px

```css
/* Small Mobile */
@media (max-width: 480px) { ... }

/* Mobile */
@media (max-width: 768px) { ... }

/* Tablet */
@media (max-width: 1024px) { ... }

/* Desktop */
Default styles (1280px max-width container)
```
